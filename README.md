# martincamenius_content

Bits and pieces that go with posts on [martincamenius.se](https://martincamenius.se).

## snippets/

Self-contained, cleaned-up code from projects I've written about. Names, URLs
and other project-specific values are replaced with placeholders, so each
folder can be copied and run on its own.

| Snippet | What it is |
|---|---|
| [`qr-codes`](snippets/qr-codes) | Printable, coloured QR code cards generated from a list |
